How can we help?

Find answers below or report an issue directly to the CasinoCompass project.

Contact support on GitHub

A GitHub account is required. Reports are public: please do not include precise personal locations, credentials, or other sensitive information.

The app shows Vancouver instead of my location

You are in demo mode. Tap the location button in the header to choose live mode. If permission was denied, enable location access for CasinoCompass in iPhone Settings, then return and select live mode. You can continue using demo without granting permission.

The compass is unavailable or points inaccurately

Live direction needs a valid compass heading. The app shows an unavailable indicator rather than a simulated live direction when heading is missing. Move away from magnetic interference and check iPhone location permissions. Distances are straight-line estimates; use the Maps buttons for a route.

Does every casino have live table games?

No. The app keeps venues such as Century Mile in its results and displays “No live table games • electronic table games only” where applicable. Other records reflect bundled information that can become outdated. Check with the venue for current games, hours, and entry requirements.

What does New Venue do?

It cycles through listed casinos within 50 km. If none are in that radius, the app shows the nearest listed venue. The dataset is not a complete or continuously updated directory.

Sharing and hidden names

Share prepares a distance card and text for the selected venue. Alternate selections and demo coordinates are identified. Hide Name also hides the venue name on the shared card. You choose a destination in the iPhone share sheet; opening it alone does not send anything.

Report a bug or incorrect venue

Include your app version, iOS version, iPhone model, what you expected, and the steps that produced the issue. For venue corrections, include the venue name and a public operator source. A screenshot can help if you remove private information first.

Safer play

CasinoCompass does not offer gambling. Follow local age and venue rules. For Canadian education and help resources, visit the Responsible Gambling Council.
